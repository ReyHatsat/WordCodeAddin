# Privacidad / Privacy

## Español

WordCodeAddin procesa el código en el equipo del usuario y lo inserta en el documento abierto. No ejecuta el código, no envía fragmentos a servicios externos, no almacena los fragmentos y no añade telemetría. El complemento necesita permiso para leer y escribir en el documento actual.

Office.js se descarga del CDN de Microsoft. La autenticación y la instalación utilizan servicios de Microsoft. El almacenamiento o la sincronización del documento depende de Word, OneDrive y de la configuración de su cuenta. Esta declaración describe el complemento, no esos servicios.

El panel y los iconos de la versión alojada se sirven desde GitHub Pages. GitHub puede registrar datos técnicos de las solicitudes, como la dirección IP, según su [declaración de privacidad](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). El texto del código no se incluye en esas solicitudes.

## English

WordCodeAddin processes code on the user's computer and inserts it into the open document. It does not execute code, send snippets to external services, store snippets, or add telemetry. The add-in requires permission to read and write the current document.

Office.js is downloaded from Microsoft's CDN. Authentication and installation use Microsoft's services. Document storage or synchronization depends on Word, OneDrive, and your account settings. This statement describes the add-in, rather than those services.

The hosted pane and icons are served by GitHub Pages. GitHub may record technical request data, such as IP addresses, under its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Code snippets are not included in those requests.
