El panel se carga desde GitHub Pages. No necesita ejecutar un servidor local, instalar Node.js ni abrir Start.cmd. Necesita conexión a Internet y Word compatible con manifiestos unificados.

Descargar complemento · 1.2.0
  1. Descargue el ZIP con el botón anterior. No lo extraiga. Guarde sus documentos y cierre Word.
  2. En Microsoft Teams, con la misma cuenta de Microsoft 365 que utiliza en Word, abra Aplicaciones → Administrar sus aplicaciones → Cargar una aplicación → Cargar una aplicación personalizada.
  3. Seleccione wordcodeaddin.zip, pulse Agregar y cierre Teams. Si no aparece la opción de carga, solicite la instalación al administrador de su organización.
  4. Abra Word y un documento editable. Busque Insertar → Código → Insertar código. Si no aparece, seleccione WordCodeAddin desde Inicio → Complementos; puede tardar unos minutos.

El idioma del panel sigue el de Word: español formal o inglés estadounidense. El código se procesa en su equipo; no se ejecuta ni se envía al servidor.

La versión local previamente instalada no cambia automáticamente. Instalar este paquete sustituye su registro por la versión alojada.

Guía completa y solución de problemas

Install once. Then open Word.

The pane loads from GitHub Pages. No local server, Node.js installation, or Start.cmd is needed. Internet access and Word with unified manifest support are required.

Download Add-in · 1.2.0
  1. Download the ZIP using the button above. Do not extract it. Save your documents and close Word.
  2. In Microsoft Teams, using the same Microsoft 365 account as Word, select Apps → Manage your apps → Upload an app → Upload a custom app.
  3. Select wordcodeaddin.zip, select Add, and close Teams. If the upload option is unavailable, please ask your organization's administrator to install the add-in.
  4. Open Word and an editable document. Select Insert → Code → Insert Code. If it is missing, select WordCodeAddin from Home → Add-ins; it may take a few minutes to appear.

The pane follows Word's display language: formal Spanish or American English. Code is processed on your computer; it is not executed or sent to the server.

An existing local installation does not change automatically. Installing this package replaces its registration with the hosted version.
